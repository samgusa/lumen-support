# Lumen Support

Thank you for using Lumen.

Lumen is a customizable video player and media library designed to give users greater control over how they organize and enjoy their personal video collections.

## Support

If you need help with Lumen, have questions, or would like to report a bug, please contact:

Email: [greenhillsam25@gmail.com](mailto:greenhillsam25@gmail.com)

## Common Features

* Import videos from Files and supported sources
* Create and manage playlists
* Organize media collections
* Customize playback controls and appearance
* Store local copies of videos
* Create reference-based collections using supported file locations

## Feedback

Feedback and feature suggestions are always welcome. We appreciate your support and are continually working to improve Lumen.

## Response Time

We aim to respond to support requests as quickly as possible, typically within a few business days.
